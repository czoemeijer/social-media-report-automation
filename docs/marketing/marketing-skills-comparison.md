# Marketing Skills Comparison

> Where both libraries provide similar skills, this document recommends the stronger implementation.

## Conflict Resolution Strategy

**Principle:** Corey Haines skills are installed under canonical names. OpenClaudia conflicting skills are installed with `oc-` prefix. Both remain available; the canonical name is used by default.

## Summary Recommendation for 2027 Strategy

For a 2027 marketing strategy engagement:
1. **Always start with** `product-marketing` (CH) for context
2. **Use CH skills as primary** for strategy, copywriting, and analysis
3. **Use OC skills for** platform-specific tools (Google Ads, LinkedIn, etc.), ICP building, and content calendars
4. **Existing workspace skills** (`social-report-audit`, `story-series-extract`, `owned-media-report`) remain essential for social media reporting
